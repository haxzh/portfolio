## ✨ Features

### 1. 🤖 Interactive AI Assistant ("Harsh AI")
- **Conversational Intelligence:** Answers questions about Harsh's background, education, tech stacks, and projects (*Locaa-AI, FounderSaathi, etc.*).
- **Interactive Quick Chips:** 1-click prompts (`💼 Hire Harsh`, `🚀 Top Projects`, `🤖 AI & RAG Tech`, `📄 Resume Details`).
- **Direct Actions:** Interactive triggers to download resume, launch GitHub repositories, or open contact dialogs right inside the chat bubble.

### 2. ⚡ Universal Command Palette (`Ctrl + K` / `⌘ + K`)
- **Keyboard-First Experience:** Fast fuzzy search across:
  - **Navigation:** Direct jump to *Home, About, Projects, Resume, Contact*.
  - **Project Finder:** Search projects by name, description, or stack with 1-click GitHub repository launch.
  - **Quick Actions:** *Download Resume*, *Copy Email*, *Open Socials*.
  - **Ambient Theme Switcher:** Instant theme switching from the palette.

### 3. 📬 Supercharged Direct Contact Hub
- **Direct Email Delivery via EmailJS:** Submits inquiries directly to Gmail without launching Outlook or external mailto clients.
- **Smart Message Intent Templates:** Pre-filled structured templates for:
  - 💼 *Job Opportunities* (Role, Company, Tech Stack, Compensation)
  - 🚀 *Freelance Projects* (Scope, Timeline, Budget)
  - 🤝 *Technical Collaboration*
  - ☕ *Quick Coffee Chat / Networking*
- **Live Local Time Widget:** Real-time India Standard Time clock (`🕒 IST UTC+5:30 • Noida, India`).
- **Direct WhatsApp Connect:** 1-click WhatsApp messaging.
- **Real-Time Counters:** Live character count and word counter for message drafts.

### 4. 🗂️ Interactive Project Discovery
- **Grid vs. List View:** Switch effortlessly between modern glassmorphism cards and dense architectural engineering rows.
- **Stack Filter Pills:** Filter by specific technologies (*Next.js 16, React, Python, Django, Flask, RAG, Supabase, OpenCV, Redis, MongoDB*).
- **Tabbed Modal Deep-Dive:**
  - 📌 *Architectural Overview*
  - ✨ *Key Engineering Capabilities*
  - 🛠 *Technologies & Libraries*
  - 🔗 *Direct Code & Live Demo Links*

### 5. 🔊 Pure Web Audio SFX Synthesizer
- Synthesized entirely using HTML5 **Web Audio API** (Zero external audio asset files!).
- Subtle micro-interaction sound effects on clicks, modal transitions, and theme changes.
- Persistent Audio Mute / Unmute toggle in the navigation bar.

### 6. 🎨 Ambient Theme Customizer
- Instant live color customization:
  - 🟣 **Cyber Violet** (Default)
  - 🔵 **Electric Cyan**
  - 🟢 **Neon Emerald**
  - 🔴 **Sunset Rose**

## ⚙️ Getting Started

### Prerequisites
- **Node.js** (v16+ or newer)
- **npm** or **yarn**

### 1. Clone the Repository
```bash
git clone https://github.com/haxzh/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Setup Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

Fill in your **EmailJS** credentials in `.env`:
```env
GENERATE_SOURCEMAP=false

REACT_APP_EMAILJS_SERVICE_ID=your_service_id_here
REACT_APP_EMAILJS_TEMPLATE_ID=your_template_id_here
REACT_APP_EMAILJS_PUBLIC_KEY=your_public_key_here
```

### 4. Run Locally
```bash
npm start
```
The application will launch automatically at `http://localhost:3000` (or `3001`).

### 5. Build for Production
```bash
npm run build
```
